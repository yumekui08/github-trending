# 0038 検索される言葉に合わせる：トップの説明を固定、ツールのページを「〇〇 とは・使い方」に、言語別の一覧、題字の下の標語

- 日付：2026-10-11
- 状態：決定（0037 のトップの題、0035 の詳しいページの題を改める）

## 背景
本人から「もっと本気で SEO を」と。各ツールの名前で検索したときに上に出ること、「GitHub トレンド」「GitHub 人気リポジトリ」などで引っかかることを狙う。また、トップを検索すると、その日のリポジトリの要約の寄せ集めが説明文として出てしまい、何のサイトか伝わらない、と。

Google の検索候補（オートコンプリート）を見ると、次の言葉で探されている（2026-10-11）。
- 大きな言葉：「github トレンド まとめ」「github 人気リポジトリ」「github 人気 ランキング」「github 人気 リポジトリ python」「github スター ランキング」「github おすすめ リポジトリ」
- ツール名：「claude-mem 使い方」「claude-mem インストール」「claude-memとは」のように「とは・使い方・インストール」が付く
- 「github ニュース」「github 新聞」は Copilot のニュースや日経が中心で、狙う相手は少ない。「github新聞」はサイト名として引っかかれば足りる

## 決定
- **トップ・週次・月次の説明文（meta description）は、毎日変わらない「何のページか」にする**。その日の要約の寄せ集めはやめる（検索結果に古い日の中身が出続けるため）。日付を指定したページ（検索に載せない）は、今までどおりその日の中身
- **トップの題**：「github新聞｜GitHub トレンドの人気リポジトリを毎朝日本語で解説」。週次は「GitHub 週間トレンド・人気リポジトリランキング（日本語解説）｜github新聞」、月次は「GitHub 月間…」
- **題字の下の標語**：どのページにも「GitHub トレンドの人気リポジトリを、毎朝日本語で」を一行。新聞の題字に添える標語として。検索エンジンにも人にも、何のサイトかが伝わる
- **詳しいページ**：題を「owner/name とは？使い方・できることを日本語で解説 | github新聞」にする。節の見出しにリポジトリ名を入れる（「Agent-Reach でできること」「Agent-Reach の使い方」など）。名前の部分は字間を広げない
- **言語別の一覧 `/lang/英字の名前/`**：その言語（最後に Trending で見たときの値）のリポジトリの解説を新しい順に。題は「Python の人気 GitHub リポジトリ一覧（トレンド入り・日本語解説）」。詳しいページの「言語」からリンクし、`/t/` を「分野別・言語別」にして並べる。sitemap に載せる
- **分野別の一覧の題**：「AI エージェントの人気 GitHub リポジトリ一覧（日本語解説）」
- **トップの構造化データ**：`WebSite` に別名（GitHub新聞、github 新聞）と、発行元（ロゴ、GitHub のリポジトリ）
- 検索に載せるページには `max-image-preview:large` を付ける（Google Discover などで大きな画像を出してよい）
- スマホで日付が2桁（10月10日など）のときに題字と重なっていたので、題字の幅を少し控えめにする
