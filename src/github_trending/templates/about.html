github新聞とは

GitHub Trending を、毎朝日本語で。

github新聞は、GitHub Trending に上がったリポジトリを毎朝集めて、日本語で要約するサイトです。いま話題のリポジトリが「何をするものか」「どう使うのか」「何に気をつけるか」を、英語の README を読まずにざっと掴めます。

なぜ作ったか

GitHub Trending には毎日、新しいツールやライブラリが上がってきます。追いかけたいけれど、英語の README を毎日いくつも読むのはつらい。そこで、日本語でざっと中身を知り、気になったものだけ原文を読みに行けるようにしました。

読めるもの

  • 今日の紙面：その日の Trending を順位どおりに。日次のほか、週次・月次のランキングも
  • リポジトリごとの解説：できること、使い方、活用できそうな場面、向いている人、似ているもの、技術、注意点、スターの推移
  • 過去の日：記録を始めた日からの紙面

どうやって作っているか

  1. 毎朝、GitHub Trending（日次・週次・月次）のページを読み、初めて上がったもの・続けて上がっているもの・久しぶりに戻ってきたものを分けます
  2. まだ解説していないリポジトリについて、GitHub API でリポジトリの情報、README、ファイルの構成などを集めます
  3. 集めた材料を AI（Claude Code）が読み、日本語で要約します
  4. 静的なサイトとして公開し、Discord にも届けます

要約では、README の宣伝文句をそのまま訳さないこと、分からないことは書かないこと、推測は推測と書くことを決まりにしています。材料が少ないものには「情報が少ない」と印を付け、解説ごとに「確かさ」（高・中・低）を添えています。同じリポジトリは一度解説したら使い回し、90日たってまた上がってきたら書き直します。

紙面の見方

  • 記事は Trending の順位どおり。1位はトップ記事として大きく、10位からは「短信」として短く並べます
  • 記事の右上の印：新 初めてランク入り、続 前回から継続、再 圏外から再びランク入り。▲▼ は前回からの順位の変化
  • 「本日の分野」は、その日の記事に多い分野です

ご注意

要約は AI が書いたもので、誤りを含むことがあります。使う前には、リポジトリの原文（GitHub）を確かめてください。このサイトは GitHub とは関係のない、個人のサイトです。

要約は、公開する前に人が一つずつ確かめてはいません。誤りに気づいたら、GitHub の Issue で知らせてもらえると助かります。
